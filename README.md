# 🧴 Персональный Парфюм-Гид (Telegram Bot)

Телеграм-бот для подбора ароматов под текущую погоду на базе Aiogram 3 и нейросети Qwen (через Groq API).

Боту скармливается коллекция парфюма (текстом), указывается город,в котором вы проживаете

При нажатии кнопки подбора - он просматривает вашу коллекцию парфюма, смотрит погоду в регионе, который вы указали, проводит анализ пирамид ароматов используя Qwen3.8 и предлагает вам лучшие вариантов парфюмов на сегодня учитывая температуру на улице

Так же бот умеет предлагать вам парфюм, иходя из ваших предпочтений. Он анализирует пирамиды ваших ароматов, и на основе нот, которые вам нравятся больше всего - предлагает варианты к покупке

## Быстрый старт

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/dr1zzyyyy/perfume-assistant-bot.git
   cd perfume-assistant-bot

2. Пропиши свои токены в .env:
   ```bash
   BOT_TOKEN - токен бота Telegram
   ROQ_API_KEY - API токен с ttps://console.groq.com/home

3. Выполняй запуск бота:
   ```bash
   run.sh - Linux
   run.bat - Windows
